# 分类与维护说明

## 仓库与展示

公开仓库：https://github.com/yue-hai/github-stars 。仅收录公开 Star 元数据与整理内容，不包含账户凭据。README.md 为简洁首页，catalog/ 下按用途分别生成分类页，catalog/all.md 为可一次全文查找的完整索引，catalog/pending.md 保留待分类入口。项目采用紧凑列表、标签与折叠备注，不使用宽表格；所有页面直接在 GitHub 阅读，无需部署。index.html 是可下载后直接打开的单文件搜索页，无 CDN 或外部请求。GitHub 文件页只显示 HTML 源码；当前未配置 Pages。

## 数据源与人工维护

- data/stars.json：公开 API 的必要字段快照；data/catalog.json 为生成产物。
- data/usage.tsv：逐项适用场景与同类工具区别，为整理建议，不代表实测；按历史名称保留，不被同步覆盖。
- data/functions.tsv：依据README/官方文档整理每个项目的主要能力与运行条件；文档缺失/有限时明确标注未知，不由同步覆盖。不是安全审计或实机测试。
- data/curation.tsv：人工中文用途、主分类、子分类、标签与备注。抓取不会覆盖此文件；取消收藏后也保留人工记录。
- data/identities.json：仓库 ID 对应的历史名称；改名或转移后继续匹配原人工分类。
- data/history.json：新增、公开列表不再可见、改名的事件历史。不再可见可能是取消 Star、仓库私有化或删除，不能武断说是取消收藏。
- data/review.jsonl 与 data/readme-evidence.jsonl：2026-10-31 首次整理资料节选，不是实时状态或源码审计。
- scripts/build.py 与 templates/index.html：生成入口和模板。修改数据后重新生成，不直接改产物。

按主要用途分类，一个项目一个主分类，平台与技术作为标签。收录不代表安全推荐、授权背书或实测可用。“未归档”仅指 API 字段。downkyi 停止维护、Fooocus 有限 LTS 为 2026-10-31 README 核对结论，需定期人工复核。

## 定时同步

工作流 .github/workflows/sync.yml：每天北京时间 **09:17**（UTC 01:17）运行；支持 Actions 页面 Run workflow 手动执行。代码、模板和人工分类变更也会触发。GitHub 可能延迟或跳过计划任务，长期无仓库活动也可能停用公共仓库计划任务；实际状态以 Actions 日志为准。

每次完整分页读取两遍，核对仓库 ID、名称与收藏时间稳定性；拒绝错误响应、私有项目、重复 ID、异常空列表及大量消失。大量移除须人工复核后本地使用 --allow-large-drop，定时任务不绕过保护。网络或构建失败不会提交覆盖远端旧目录。

当前公开列表移出消失项目，Git 历史、事件历史和人工用途记录保留。新增项目先放“待分类”，显示原始描述，等待人工补充中文用途；没有接入付费模型或自动 AI 分类。

仅有效字段变化时提交，纯抓取时间变化不提交。有效字段含 Star 数、最近推送、描述等，因此即使收藏名单不变，也可能因热度或元数据变化产生提交。没有变化时保留原快照日期；工作流日志仍记录检查运行。

工作流只使用目标仓库自己的 GITHUB_TOKEN（contents: write），不需要上传 SSH 密钥。不更改用户 Star，不读取私有收藏，不操作原项目。Actions 设置若禁用自动运行或令牌写权限，需要在仓库 Settings → Actions 中检查策略。

## 本地命令

Python 3.9+，不需安装第三方 Python 包；本机 Python HTTPS 不兼容时以 curl 验证证书回退，不关闭 TLS 验证。

```
python3 -m unittest discover -s tests -v
python3 scripts/sync.py
python3 scripts/build.py
```

仅构建无需联网。原项目许可归各自作者；本仓库不复制或分发收藏的软件。
