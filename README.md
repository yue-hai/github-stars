## 查找与更新

- **找工具**：从用途分类进入；想一次搜索全部内容，打开[全部收藏](catalog/all.md)后按 Ctrl/Cmd+F。
- **仓库内搜索**：使用 GitHub 搜索，例如 `repo:yue-hai/github-stars path:catalog 剪贴板`；代码索引可能延迟。
- **自动同步**：每天北京时间 **09:17 左右**检查，GitHub 调度可能延迟；可在 Actions 手动运行。
- **新收藏**：先进入待分类；已有人工用途和备注不会被自动覆盖。
- **变更追溯**：[收藏变化数据](data/history.json)与 Git 提交历史保留记录；项目从公开列表消失不一定意味着取消 Star。
